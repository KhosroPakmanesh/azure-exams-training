# Margie’s Travel brochures

This app follows the Microsoft Learn exercise. Copy the **original brochure PDF files**
from `labfiles/tools/python/tools-app/brochures/` in the MicrosoftLearning
`mslearn-ai-studio` repository to any local directory, then pass that directory as
an argument when running Project 11.

Official lab: https://microsoftlearning.github.io/mslearn-ai-studio/Instructions/Exercises/04a-use-own-data.html
Official files: https://github.com/MicrosoftLearning/mslearn-ai-studio/tree/main/labfiles/tools/python/tools-app/brochures

This project does not invent or bundle travel brochures. If you already have a
vector store with the documents, pass the `vs_...` ID instead.
